# Slot 10: Cleanup

> **Goal:** Tear down the playground and wrap up the workshop.

## Tear down the playground

Navigate to the cnpg-playground directory and run the teardown script:

```bash
cd <path-to>/cnpg-playground
./scripts/teardown.sh
```

This removes the Kind clusters, RustFS containers, and associated volumes.

exploring cluster creation, backup and recovery, observability, resilience,
plugin commands, declarative logical replication, and extensions.
